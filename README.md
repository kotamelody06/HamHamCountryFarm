# はむはむカントリーファーム ～小さなお手伝いさんとスローライフ～

企画構想シートをもとにした、Android向け Godot 4 プロジェクトです（GDScript・縦画面・タッチ操作）。
画像素材がなくても遊べるよう、キャラクター・作物・お部屋などはすべてコードで描画しています。

## すぐ遊ぶ（APK）

`hamuhamu_country_farm_v1.9_arm64.apk` をAndroid端末（Android 7.0以上）にコピーしてインストールしてください。
「提供元不明のアプリ」の許可が必要です。テスト用の署名なので、Google Play公開時は下記の手順でご自身の鍵で書き出し直してください。

## Godotで開く・書き出す

1. **Godot 4.3 以降**（標準版）でこのフォルダの `project.godot` を開く
2. エディタで F5 を押すとPC上で縦画面のままテストプレイできます（マウスでタップ・ドラッグでスクロール）
3. Android向けに書き出す
   - エディタ設定 → エクスポート → Android で **Android SDK** と **Java SDK（JDK 17）** のパスを設定
   - エディタ → エクスポートテンプレートを管理 → ダウンロード
   - プロジェクト → エクスポート → 「Android」プリセット（設定済み）→ プロジェクトのエクスポート
   - Google Play向けは「Gradleビルドを使用」をONにして AAB 形式、リリース用キーストアを設定

## ファイル構成

```
project.godot         縦画面720x1280・GL Compatibility（幅広いAndroid端末向け）
export_presets.cfg    Android書き出し設定（パッケージ名 com.hamuhamu.countryfarm）
scenes/main.tscn      メインシーン
scripts/game_data.gd  ★作物・料理・ハムスター・村人・クラフト・イベントのデータ（バランス調整はここ）
scripts/game.gd       ゲームのルールと状態・セーブ（オートロード "Game"）
scripts/main.gd       画面（タブ・ポップアップ・タイトル・イベント）
scripts/art.gd        キャラクター・作物・お部屋の描画
scripts/sfx.gd        サウンドマネージャー：効果音とBGM（オートロード "Sfx"）
sounds/               効果音（wav）・BGM（bgm_title.ogg / bgm_main.ogg）
ui/                   UI画像（スプラッシュのロゴ、タイトルロゴ、農業レベルのアイコン・背景、水やり・収穫・木を切るボタン、たね袋・はたけの見出し、作物14種のアイコン。SVGなので同名で差し替え可）
tools/make_icons.py   畑まわりのアイコン（たね袋・はたけ・作物14種）を作り直すスクリプト
tools/make_logo.py    タイトルロゴ（ui/title_logo.svg）を作り直すスクリプト（Python3＋fontTools）
tools/make_bgm.py     BGMを作曲・合成し直すスクリプト（Python3＋numpy/scipy＋ffmpeg）
tools/make_sfx.py     効果音を合成し直すスクリプト（Python3＋numpy/scipy。書き出し時は除外）
fonts/                日本語フォント（Noto Sans CJK JP を JIS 第1・第2水準に絞ったもの／SIL OFL）
tests/                自動テスト（書き出し時は除外）
```

## カスタマイズのヒント

- **数値の調整**：`game_data.gd` の値（種代・売値・日数・価格倍率など）を書き換えるだけで反映されます
- **イラストへの差し替え**：`art.gd` の各関数（`hamster` / `player` / `plot` / `item_icon` など）の中身を `draw_texture()` に置き換えれば、描画を画像に差し替えられます
- **効果音の差し替え**：`sounds/` の同名wavを置き換えるだけ。音色を調整したいときは `tools/make_sfx.py` の数値を変えて `python3 tools/make_sfx.py` を実行
- **自動テスト**：`godot --headless --path . res://tests/test_runner.tscn`（ロジック一式と全画面の表示を確認。120日分のランダムプレイも実行）
